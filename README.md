# Airbnb Seattle Market Analysis

Tableau dashboard exploring Seattle's Airbnb market pricing, availability, 
neighborhoods, and guest reviews built from listings, calendar, and review data.

## Dataset
- Listings: 3,818 rows (price, room type, neighborhood, host info, review scores)
- Reviews: 84,849 rows (guest reviews with dates and comments)
- Calendar: 1,048,575 rows (daily price and availability per listing)

## Tools
- Tableau Desktop
- Excel

## Key Questions Explored
- Which neighborhoods have the highest/lowest prices?
- How does price vary by room type?
- How does availability change over the year?
- What drives higher review scores?
- Do Superhosts get better prices/ratings?

## How to Use
1. Clone the repo
2. Open the `.twbx` file in Tableau Desktop or Tableau Public
3. Reconnect the data source if prompted
